## Acceptance notes

- Motion must be observed on the real application routes, not inferred only
  from CSS text or a copied static HTML page.
- Hover behavior is visual enhancement only. Essential navigation, search,
  product, cart, checkout, and CTA actions must remain keyboard- and touch-
  usable.
- Page entrance and scroll reveal must never hide required content when the
  observer or animation API is unavailable.
- The current app has no confirmed authoritative testimonials, statistics,
  newsletter submission, or reference-only routes. Their inventory entries
  therefore remain presentation-only/conditional and do not authorize fake
  data or success responses.
