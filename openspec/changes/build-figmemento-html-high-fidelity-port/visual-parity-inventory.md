# Visual Parity Inventory

Reference: `docs/design-reference/figmemento-fusion-design-v2.html` (Fusion
Design v1.1). Current implementation references are the real application as
found in `app/storefront/CatalogShell.tsx`, `app/storefront/CatalogDiscovery.tsx`,
`app/page.tsx`, `app/storefront/catalog-storefront.module.css`,
`app/storefront/fusion-foundation.module.css`, and `app/globals.css`.

This inventory is a pre-implementation review artifact. “Required port” means
the Batch A target; it does not authorize changes to business authority.
